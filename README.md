# EmCoin Guided Portfolios — Institutional Grade MVP

Core architecture: Customer → Risk/KYC/AML → Investment Account → Subscription → Portfolio.

Includes PostgreSQL schema, SQLAlchemy 2, Alembic, FastAPI/OpenAPI, JWT/RBAC, suitability, simulator, subscriptions/events, consents and audit trail.

See PROJECT_MANIFEST.md for scope and run with Docker Compose.
